# Better MC BMC4 custom

Couche custom par-dessus Better MC [FORGE] BMC4.
Minecraft 1.20.1, Forge 47.4.20.

Ce dépôt ne contient pas les mods, les mondes, les caches, ni `minecraftinstance.json`.
Les jars restent ceux de CurseForge. Ici, il n'y a que les fichiers modifiés.

## Mods à ajouter au pack de base

- Apotheosis 1.20.1-7.4.8
- Apothic Attributes 1.20.1-1.3.7
- Apothic Curios 1.20.1-1.0.3e
- apothic_category_compat 2.1.0
- Placebo 1.20.1-8.6.3
- In Control 1.20-9.5.0

Paxi 1.20-Forge-4.0 est déjà dans BMC4.
PuzzlesLib reste installé.

Easy Anvils, Easy Magic, Easy Disenchanting et Spawners+ sont retirés.

## Fichiers suivis

- `config/apotheosis/adventure.cfg`
- `config/incontrol/spawn.json`
- `config/dragonmounts-common.toml`
- `config/paxi/datapacks/apotheosis_dim_mob_loot/`

Le détail du transfert serveur est dans `transfert-nitroserv.txt`.
